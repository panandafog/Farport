# Farport support / Поддержка Farport

## English

Farport is an SSH terminal for Mac, iPhone and iPad. The Mac app also supports
SFTP and remote folders in Finder.

For help, email [panandafog@icloud.com](mailto:panandafog@icloud.com) or
[open an issue](https://github.com/panandafog/Farport/issues).
Include the app version, device/OS version, the action you attempted and a redacted
error message. **Never send passwords, private keys, full host libraries or confidential
terminal output.** GitHub issues are public.

- [Usage](../Docs/Usage.md)
- [Connection and credential security](../Docs/Security.md)
- [iCloud setup and troubleshooting](../Docs/iCloud.md)
- [Privacy policy](privacy-policy.md)

Verify your server's address, SSH port and credentials if a connection fails.
When importing hosts through iCloud, set credentials separately on each device.
Public demo servers are operated by third parties; the developer cannot reset
accounts or change permissions on your servers.

## Русский

Farport — SSH-терминал для Mac, iPhone и iPad. На Mac также доступны SFTP
и подключение удалённых папок в Finder.

Напишите на [panandafog@icloud.com](mailto:panandafog@icloud.com) или
[создайте issue](https://github.com/panandafog/Farport/issues).
Укажите версию приложения, устройство и версию ОС, действие и обезличенный текст
ошибки. **Не отправляйте пароли, приватные ключи, полную библиотеку хостов
или конфиденциальный вывод терминала.** Обращения на GitHub видны всем.

- [Использование](../Docs/Usage.md)
- [Безопасность подключений и данных входа](../Docs/Security.md)
- [Настройка и диагностика iCloud](../Docs/iCloud.md)
- [Политика конфиденциальности](privacy-policy.md)

При ошибке подключения проверьте адрес, SSH-порт и данные входа.
Для импортированных из iCloud хостов задайте данные входа отдельно на каждом устройстве.
Разработчик не управляет серверами пользователя и сторонними публичными серверами.
